## 三、执行过程中发现并修复的缺陷（T52）

| 缺陷 | 根因 | 修复 | 回归 |
|------|------|------|------|
| 退出后主题等最后变更丢失 | before-quit 中异步 flush 被进程退出截断 | preventDefault → await 落盘 → 再 quit | E2E 验收6 ✅ |
| 主进程 "Object has been destroyed" 原生弹窗（阻塞退出）| 窗口销毁后仍经旧引用访问 | safeWin() 守卫 + closed 置空引用 | 全量 E2E 11/11，无弹窗、无挂起 ✅ |
| 主窗口 preload 未加载（API 不可用）| createWindow 未传 preload 路径 | webPreferences 补 preload | 全量功能用例 ✅ |
| 多窗口状态不同步 | 子窗口提交后未广播 | commit 后向全部窗口推送最新状态 | E2E 主流程 ✅ |
| Git Bash 下 NSIS /S 被路径转换吞掉 | MSYS 参数改写 | 改用 PowerShell Start-Process | T50 ✅ |
