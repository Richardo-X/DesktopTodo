① 架构（v1.1.6）
  • 三窗 + 白条独立窗（第 4 窗）：主窗 / 快捷 / 已完成 + 缩进白条；拖任一标题栏＝整组移动。
  • 缩进＝整组三窗瞬间移出屏幕顶边之外（几何不变、不隐藏、不改透明度＝集合不变）；弹出＝白条收＋整组同一次落位；无过渡动画。
  • 白条：热区 160×6、可见条 3px、贴屏幕最顶；水平位置＝主窗上缘中心（不算侧窗）；只认“碰”，点击不弹出。
  • 3 秒停留自动缩回、托盘隐藏/显示、Win+D 免疫照旧。
② 视觉/排版（L1+L2）
  • 字号六档 38 / 15 / 13.5 / 12 / 11 / 10；列表行 11×12、gap 8；正文行高 1.5；面板标题 15。
  • 缩放锚点＝主窗左上角；侧窗 310×640；缩放只作用于各窗内容，4px 缝隙不随缩放变化。
  • 图标按钮 32×32 浅底＋描边；小按钮 26px、主按钮 30px。
③ 批量（v1.1.4）
  • 批量条＝已选 N 项｜全选/取消｜删除所选；返回在各窗「批量删除」左侧同排（8px）。
  • 单目标批量；非目标窗口整体冻结 0.7，窗内被禁控件 0.45；历史窗导航逐控件冻结，返回保持可点。
④ 二级窗（v1.1.3）
  • 基准尺寸：新建待办 420×400 / 编辑待办 420×388 / 新建模板 420×428 / 编辑模板 420×392 / 详情 415×245 / 历史 645×620 / 设置 460×540。

  • 设置窗：覆盖导入/合并导入、上限受当前待办数约束；详情窗属性块＋右下关闭。
