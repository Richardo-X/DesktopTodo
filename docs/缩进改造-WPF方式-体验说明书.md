# 桌面待办 · 缩进系统改造（WPF 方式）体验说明书

> 依据：WPF 版 R1「缩进/弹出重设计」（`todo-wpf/docs/需求文档-wpf.md` 修订记录 R1，已逐行对照其实现：`TuckStateMachine` / `TuckBarWindow` / `ClusterController`）
> 你的裁定（2026-10-17）：**不做过渡动画**（先不需要）、**集合不变**（缩进不改变窗口集合）
> 基线：3bbe639（v1.1.5 待验收轮之上）；本批独立成一轮，不混入 v1.1.5 的验收。

---

## 一、这批做什么（一句话）

把缩进从"**主窗收成胶囊 + 侧窗原地隐形**"改成 WPF 版的"**整组三窗一起移出屏幕顶边之外（瞬间跳位，无动画）+ 白条作为独立小窗出现**"；**缩进不再改变窗口集合**——侧窗不隐藏、不透明化，跟着整组一起移出屏外，弹出时同一套窗口原样回来。

## 二、先说清楚：你会看到什么变化（很少，如实说）

因为不做动画，"整组移出屏外"与今天的"原地隐形"在屏幕上几乎是同一件事——**缩进/弹出的观感与今天基本一致**。真正变化的是：

| # | 变化 | 说明 |
|---|------|------|
| 1 | 缩进瞬间：整簇（含侧窗）**整块一起离场**；主窗不再"缩成一条" | 无动画、瞬间；肉眼与今天差别很小 |
| 2 | 白条改为**独立小窗**呈现（不再是主窗折叠的那条） | 白条视觉保持你的口径：可见 3px / 热区 6px、贴工作区顶、鼠标碰到才弹出（被遮挡天然不弹）、点击也可弹 |
| 3 | 弹出瞬间：三窗**同一次落位一起回来** | 今天是"侧窗先出现、主窗展开"两步 |
| 4 | **（待你一句话拍板）白条水平位置** | WPF 口径=整组水平中心（含侧窗）；今天=主窗上缘中心（不算侧窗）。侧窗打开时两者差约 157×缩放 像素。**默认按 WPF 口径**，你说"保持现状"就保持现状 |
| 5 | 缩进态侧窗**不再被"隐藏"**，只是整组都在屏幕外 | 与 WPF 一致；观感无差别，属结构变化 |

**顺带的架构收益（你无感，但以后少生 bug）**：主窗不再有"被收成 160×6 胶囊"的畸形态与系统最小窗高钳制的特殊处理（昨天那套补丁只留给白条窗用）；缩进=纯位移——三窗尺寸与内容全程不变（不缩放、不重排）；白条职责单一。

## 三、明确不变的（回归验收用）

操作与门槛全套不变：贴边吸附才缩进；鼠标离开约 0.5s 自动缩进；碰白条弹出、点白条也可弹；缩进锁定（贴边保持弹出）；二级窗开着始终弹出；拖动/缩放/批量中不缩进；托盘恢复自动弹出停留 3 秒（到期光标不在组件上缩回）；托盘显隐、置顶、主题、Win+D/M 语义、缩进态缩放柄不可达——全部照旧。白条厚度/贴顶/悬停微亮/真实命中语义原样。

## 四、怎么验证（真机）

1. **缩进**：三窗瞬间离场、白条出现（位置按你裁定的口径、厚度与今天一致）；鼠标移到白条上→弹出；点白条也能弹；
2. **缩进态桌面**：白条以外的屏幕区域完全不受影响（点桌面图标/其他软件正常、不乱弹）；
3. **遮挡**：缩进态拿另一个窗口盖在白条上→从它上面划过**不弹**（真实命中语义保持）；
4. **托盘**：缩进态托盘隐藏→显示→自动弹出停留 3 秒→到期自动缩回；弹出态托盘隐藏→显示→原位恢复、三窗同步到位；
5. **门槛**：缩进后光标停在白条上不动（不弹）；拖缩放柄/进批量/开二级窗→组件保持弹出、不缩进；
6. **边界**：把组件拖到另一块屏再缩进（贴新屏工作区顶）；若你的屏幕**上方**还有另一块屏，"移出"目标取在全部显示器最顶边之上（不会串到上方那块屏）；顶部任务栏也不受影响；
7. **回归抽查**：主题/置顶/位置记忆/跨天结算与 v1.1.5 一致。

**什么算通过**：1~7 全过 + 自动化测试全绿；观感结论以你真机为准。

| 步 | 做什么 | 你会看到 |

## 六、明确不做的

过渡动画（本批不做）；触发门槛；白条视觉（除第 4 条位置口径待定）；三窗尺寸/缩放/拖动/缝隙；二级窗与批量逻辑；样式令牌；不升级依赖、不做无关重构。

## 七、风险与纪律

- 主要风险=**离屏正确性**（多屏/任务栏边界）与**缩进链路回归**（3 秒会话/锁定/二级窗门/拖动伪 leave/批量门）——逐条重验，给出全量测试绿证据；当年 C5"屏外悬挂"的翻车点（主进程执行与渲染层白条态分裂=露出"标题条"）在新结构里由"白条=独立窗、主进程统一编排"消除。
- 每步一笔独立提交、可单独回退；测试与实现分笔；vitest + E2E + 构建全绿才提交；你说"没效果/有问题"→先把该步干净回退到上一个已确认可用状态，再谈下一步；观感以你真机结论为准。
