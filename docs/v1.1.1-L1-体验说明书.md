## 一、这批做了什么（一句话）

把 v3.4 原型里的 L1 视觉精修（≈30 处 CSS 参数）**原值落地**到应用：文字对比度、投影色调、圆角阶梯、按压反馈、时钟等宽、对话框规格，以及过渡曲线与动效关怀。
**布局、交互、功能零改动**——所有你已验收的操作手感、窗口行为、显隐语义全部保持原样。

## 二、你会看到的变化（按验收六项对照）

| # | 看什么 | 旧（v1.1.0） | 新（v1.1.1 = v3.4 原型） |
|---|--------|-------------|--------------------------|
| 1 | **文字对比度** | 副文本灰 `#666`、淡文本 `#9a9a9a`（白天） | 更清晰的新灰族：主文本 `#1a1c20`、副文本 `#5d616b`、淡文本 `#8b8f99`（夜晚同步 `#f2f3f5 / #abafb8 / #7d818c`）——小字更清楚，层次更分明 |
| 2 | **阴影色调** | 纯黑投影 `rgba(0,0,0,…)` | 蓝黑投影 `rgba(10,20,40,…)`（拖动中的待办行、模板行、气泡、确认框、蒙层）——深色下不再"发灰发脏" |
| 3 | **圆角** | 按钮/勾选框/输入框等 5px | 统一 6px 阶梯（勾选框、＋框、批量按钮、二级窗按钮、设置步进器、日期框、标题栏品牌方块…全应用一致） |
| 4 | **按压反馈** | 按钮按下无反馈 | 按下瞬间轻微缩小（scale 0.96，120ms 缓出）——点击"有手感"；勾选框、图标按钮、批量/二级窗按钮全部生效 |
| 5 | **时钟等宽** | 数字宽度随字形变化（跳动） | 时间显示用等宽数字 + Display 字体——**秒级刷新时数字不再左右抖动** |
| 6 | **对话框大小** | 宽 240~320px、圆角 12、单层黑投影 | 宽 `min(420px, 88vw)`、圆角 10、双层蓝黑柔和投影、内边距加大——长文案（如覆盖导入警告）一行放得下，观感更从容 |

另有 4 项"看不见但能感觉到"的：
- **键盘焦点描边**：按 Tab 键走查时，当前焦点按钮出现主题色 2px 描边（鼠标点击不出现——不打扰鼠标用户）；
- **统一缓出曲线**：所有变色/悬停过渡走同一条 `cubic-bezier(.22,.61,.36,1)`，观感更顺；
- **行悬停过渡**：待办行/模板行/已完成行/历史行悬停变色、拖动投影都有 150ms 平滑过渡；
- **系统减弱动效关怀**：系统开启"减少动画"时，本应用全部过渡/动画自动关闭。

## 三、怎么操作验证（真机验收步骤）

1. **对比度**：看主窗标题栏"桌面待办"、时钟下方日期、已完成行时间、快捷添加底部说明小字——应比 v1.1.0 明显更清晰；点主题按钮切夜晚再对比一遍。
2. **阴影色**：长按待办行手柄拖动 → 拖动中行的投影应偏"蓝黑"；悬停一条被截断的待办 0.5 秒 → 气泡投影同样偏蓝黑。
3. **圆角**：放大看行右端勾选框、⚡/☑/＋ 按钮、批量条按钮、"已完成"窗底部「🕘 历史记录」按钮——圆角一致 6px；打开任一二级窗（设置/新建/编辑），按钮/步进器/日期框同为 6px。
4. **按压反馈**：鼠标按住"批量删除"或任一图标按钮不放 → 按钮轻微缩小，松开复原。
5. **时钟等宽**：盯住主窗时钟看分钟跳变（或秒级刷新）——数字位置不左右抖动。
6. **对话框**：主窗进批量 → 选一项 → 删除所选，弹出确认框——明显更宽（最高 420px）、圆角更柔和、投影双层过渡自然；设置窗"覆盖导入"的长警告文案观感更从容。
7. **回归确认（重要）**：白条弹出/缩进、三窗显隐、批量流程、二级窗缩放、气泡、置顶、跨天结算——**应与 v1.1.0 完全一致**，任何手感差异都算不通过。

**通过标准**：上述 1~6 与 v3.4 原型观感一致；第 7 项无任何行为变化；无明显异常（错位/闪烁/卡顿）。

## 四、明确不动的（零触碰声明）

- v3.3 原型文件保留为纯净基线，未做任何修改。

## 六、验收反馈修正（2026-10-10 用户首轮验收发现，已对齐 3.4）

| 反馈项 | 修正前 | 修正后（= 3.4 原型） |
|--------|--------|----------------------|
| 快捷添加按钮图标 | 字符 `⚡`（Windows 渲染为**彩色 emoji**，与原型单色线性图标不符） | 原型同款 **SVG 线性闪电**（16px、currentColor——开启时随主题色蓝显、关闭时随文本色） |
| 已完成窗空列表文案位置 | 贴在列表区**顶部**（`.list-wrap` 为 block，空态 `flex:1` 失效） | **垂直居中**于列表区（与 3.4 一致；已补 `flex` 列上下文修复根因） |
| 操作区两枚图标不等大（⚡ 比 ☑ 大） | ⚡ 为 16px SVG（墨迹高 13.3px）、☑ 为 12.5px 字符字形（墨迹高约 9px）——同排观感不一致 | ☑ 换为原型 **`panelCheck` SVG**；⚡ 等比缩放至墨迹与 ☑ **同高**（光学配平，技能 3.C 图标系统一致性）；两枚均 16px 盒、路径保持原型原样 |
